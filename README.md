# SPK Gizi SAW - Sistem Penilaian Gizi

[![Streamlit App](https://img.shields.io/badge/Live_Demo-FF6B6B?style=for-the-badge&logo=streamlit&logoColor=white)](https://spk-gizi-saw.streamlit.app)

Sistem Pendukung Keputusan dengan metode **Simple Additive Weighting (SAW)** untuk menilai status gizi siswa.

## ✨ Fitur
- 📊 Dashboard interaktif
- ⚖️ Perhitungan IMT otomatis  
- 🏆 Ranking siswa terbaik
- 📥 Export Excel/CSV
- 🎨 Tema modern

## 🚀 Local Setup
```bash
git clone https://github.com/MuhRaihan123/spk_gizi_saw
cd spk_gizi_saw
pip install -r requirements.txt
streamlit run app.py
